# FDE 交付知识底座

本 Skill 是 **FDE 企业交付专家团**的方法论出处库。它不产生新观点，只负责**让每一条专业结论都能被指回原篇**。

## 何时使用

- 需要引用具体方法论（如"五层选择树""问题合同""三笔 ROI""Golden Set"）时 → 查 `references/method-cheatsheet.md`
- 需要给出篇目编号与原文链接时 → 查 `references/article-index.md`
- 需要确认某个主题**是否已经归档**（避免引用不存在的篇目）时 → 查两个文件末尾的缺篇提示

## 引用规范（团队统一口径）

1. **篇号引用**：写作 `指南 26`（两位数字，与原文标题一致）。
2. **模块引用**：写作 `M06`，模块归属以 `article-index.md` 的"三阶十五模块"为准。
3. **给链接**：引用时同时给出原文链接，格式 `指南 26 · <url>`。
4. **缺篇不得虚构**：指南 64—75 尚未归档。涉及这些主题时，必须明确标注"原文尚未归档"，改用上位原则表述，**严禁编造该篇的方法细节**。
5. **专栏与正文区分**：6 篇读书拆解、2 篇行业观察、1 篇招聘解读、1 篇系列导读属于**专栏/配套**，不计入 75 篇正文。引用时标注"配套"。
