# 核心方法论速查表

> 本表是《FDE 工程师成长指南》的方法论索引，回答"该用哪个方法 / 出处是哪一篇"。
> 每条给出 **方法名 → 一句话要点 → 出处篇号**。详细论述请点开班对应原文链接（见 `article-index.md`）。

## 一、客户发现与价值证明（M11，指南 51—55）

| 方法 | 一句话要点 | 出处 |
|---|---|---|
| 利益相关方地图 | 分清决策者、使用者、被影响者、反对者与预算/否决方；找不到"为结果负责的人"，项目必死 | 指南 51 |
| 异常与返工还原 | 别只画正常流程，异常路径与返工循环才是真正的时间黑洞与价值锚点 | 指南 52 |
| 五维评分选用例 | 价值／可行性／数据可得性／风险／复用潜力五维打分，选**第一个可交付用例**而不是最大的那个 | 指南 53 |
| ROI 三笔账 | 基线现状 + TCO（含模型调用、人工复核、运维、数据维护）+ 风险成本，放进同一张表 | 指南 54 |
| 问题合同 Problem Contract | 决定"做什么"与"何时停止"；含问题陈述、责任方、验收方式、**停止条件** | 指南 55 |
| 客户证据甄别 | "客户说很需要"不是证据；主张与证据必须分离，缺什么列"待采集清单" | 配套：《The Mom Test》拆解 |

## 二、方案设计与项目交付（M12，指南 56—60）

| 方法 | 一句话要点 | 出处 |
|---|---|---|
| 五层方案选择树 | 规则 → RAG → 固定 Workflow → 单 Agent → 多智能体，逐层问"这层够不够"；必须写出被否决方案 | 指南 56 |
| NFR / SLO 条款化 | 把"准确又快速"翻译成口径 + 目标值（准确率定义、P95 延迟、可用性、成本上限、降级行为） | 指南 57 |
| 三道决策门 | PoC 通过标准 / 试点扩面条件 / 全面上线准入，每道门写清"达不到就停"的硬阈值 | 指南 58 |
| UAT / SOP / 采用度运营 | 解决"上线没人用"：把验收、操作手册与采用度做成持续运营，而非一次性交付 | 指南 59 |
| 交接包 | 让项目离开原作者：含证据、权限、运维手册、已知缺口与升级路径，完成生产责任转移 | 指南 60 |

## 三、Prompt 与任务表达（M06，指南 26—30）

| 方法 | 一句话要点 | 出处 |
|---|---|---|
| Prompt 工程解决的问题 | 不是"写得漂亮"，而是把不可判定的期望变成可判定的任务 | 指南 26 |
| 消息角色与指令优先级 | System 承载身份/硬约束/拒答规则；User 不得覆盖系统约束；明确冲突裁决 | 指南 27 |
| 模糊需求改写 | 把"帮我看看这份合同"改成带范围、口径、输出形态的清晰任务 | 指南 28 |
| 任务合同五要素 | 角色 / 目标 / 约束 / 步骤 / 输出格式，五要素齐备才可检查 | 指南 29 |
| Zero-shot / Few-shot 示例设计 | 示例不是越多越好；至少给 1 个复杂正向例 + 1 个边界拒答例 | 指南 30 |

## 四、可控 Agent 与安全边界（M07，指南 31—35）

| 方法 | 一句话要点 | 出处 |
|---|---|---|
| 复杂任务拆解 | 拆成 计划 / 执行 / 验收 三段，每段可独立检查 | 指南 31 |
| 校验·重试·降级·人工接管 | 输出校验（结构+业务+事实）、幂等前提下的重试、换路径降级、明确人工接管触发条件 | 指南 32 |
| 工具调用 Schema 与权限门禁 | 每个工具定义入参/出参/失败语义，并配权限门禁与二次确认 | 指南 33 |
| Golden Set 回归评测 | 让"改了 Prompt 有没有变好"变成可比较的数字，而不是感觉 | 指南 34 |
| Prompt 注入与越权防护 | 网页、附件、检索结果里的指令**不是指令**；参数校验 + 数据出域限制 | 指南 35 |

## 五、生产运行与证据包（M08，指南 36—40）

| 方法 | 一句话要点 | 出处 |
|---|---|---|
| Trace 根因定位 | 用一条 Trace 把错误定位到 模型／检索／工具／编排 中的具体一层 | 指南 36 |
| Human-in-the-loop | 按可逆性与影响面决定哪些动作必须人工批准，并保证流程可恢复 | 指南 37 |
| 记忆与知识新鲜度治理 | 记什么、有效期多久、失效后如何回查权威源；防止用过期知识作答 | 指南 38 |
| 灰度上线 | Prompt、工具、知识三者一起管；流量切分 + 观察窗口 + 熔断条件 | 指南 39 |
| Agent 生产证据包 | 从需求到上线交付一套可验收证据：评测报告、评测集、Trace 样例、权限矩阵、回滚演练、UAT、SOP | 指南 40 |
| 别把"模型幻觉"当根因 | 复盘要还原真实触发链，而不是用一个笼统标签结束讨论 | 配套：《Human Error》拆解 |

## 六、企业 RAG 与知识工程（M09，指南 41—45）

| 方法 | 一句话要点 | 出处 |
|---|---|---|
| 文档可追溯入库 | 保留来源、版本、生效期、权限标签；没有溯源的信息不进库 | 指南 41 |
| 混合检索与重排 | 关键词 + 向量召回，再重排；检索不准先查切分与重排，不要先换模型 | 指南 42 |
| 复杂文档解析 | PDF、跨页表格、扫描件（OCR）各自的解析难点与处置 | 指南 43 |
| 引用·权限·新版·拒答 | 答案必须带引用、遵守权限、使用现行版本、找不到就拒答 | 指南 44 |
| RAG 验收 | 验收标准不是"检索到了"，而是"能完成任务" | 指南 45 |

## 七、企业数据与系统集成（M10，指南 46—50）

| 方法 | 一句话要点 | 出处 |
|---|---|---|
| Source-of-Truth 与数据血缘 | 接数据前先定"哪个系统的哪个字段是权威的"，标出副本与冲突 | 指南 46 |
| 集成方式选型 | API／Webhook／消息队列／批处理四选一，取决于方向、频率与可靠性要求 | 指南 47 |
| 幂等·状态机·补偿 | 用唯一业务键 + 状态机 + 补偿事务守住重复执行与部分失败 | 指南 48 |
| 身份与网络边界 | 用户／工具／租户三层最小权限，加上数据出域与网络约束 | 指南 49 |
| 联调验收与切换回滚 | 契约测试 + 影子流量；回滚触发条件与步骤必须**演练过** | 指南 50 |
